Elevator dispatch simulation

Which car should each passenger take? Four rules, called schedulers, compared on the same passengers.

The idea

Four schedulers, in the order I built them. Each one counts something the one before it ignored.

Ticks per trip: the average total time, wait + travel, over the three traffic patterns below. Shorter is better.

Minimum, average and maximum

The statistics the assignment asks for. Each cell is min / average / max, in ticks.

The longest wait

The average is efficiency. The longest wait is fairness: the unluckiest passenger.

least_combined_timethe other threeTicks the unluckiest passenger waits for a car. Shorter is better.

When every stop costs time

With a stop time of N, a car stays N more ticks whenever anyone steps in or out. Average total time at stop time 0 → 1 → 2.

What the numbers say

    Run it yourself

    python3 -m elevator_sim.scenarios                 # the comparison above, stops free
python3 -m elevator_sim.scenarios --stop-time 1   # the same when every stop costs one tick
python3 -m elevator_sim data/sample_requests.csv --cars 2   # one request file, one scheduler

    Every number on this page was produced by the simulator in this repository.
