Elevator dispatch simulation

Which car should each passenger take? Four rules, called schedulers, compared on the same passengers.

The idea

Four schedulers, in the order I built them. Each one counts something the one before it ignored.

Ticks per trip: the average total time, wait + travel, over the three traffic patterns below. Shorter is better.

All the statistics

What the assignment asks for, in ticks. Each min and max is averaged over the 20 sets of passengers. least_combined_time has the lowest average and the lowest max, of both wait and total time, in every pattern.

How I know it is right

85 tests, of four kinds. Each kind catches what the others miss.

CheckWhat it showsWhat it would miss
Hand-traced examplesExact numbers on small cases, traced on paper first.Cases nobody thought of.
The rule checkerFive rules on every finished run: everyone served, capacity, direction, legal movement, records that match the log. It shares no code with the simulation.A run that keeps every rule but has wrong times.
300 random buildings per scheduler1–10 cars, 2–50 floors, room for 1–10, stop time 0–2. Every run must pass the rule checker.Whether the choices are good. That is measured on Results.
No use of later requestsBy design, a scheduler is given only the passenger asking now and the cars as they are now. By test, a request added halfway changes nothing before it.Whether the choices are good.

Limits, and what I would build next

LimitWhat I would buildWhere the code changes
A choice of car is final.Move a waiting passenger to a better car before they board.simulation.py: offer the people still waiting to the scheduler again each tick. car.py: a way to take someone off a car's waiting list.
An idle car stays where it stopped.Park idle cars where requests are likely, such as the lobby in the morning.car.py: _choose_direction heads a car with no work to its parking floor. The floor is a setting in config.py.
Every car serves every floor.Express cars and zones. They pay off when stops cost time.config.py: the floors each car serves. schedulers.py: available() offers only cars that serve both floors. rule_checker.py: one more rule.
